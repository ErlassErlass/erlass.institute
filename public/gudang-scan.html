Cara Penggunaan
1

Set URL & Token

Buka tab SETUP. Masukkan Web App URL dari script Google Anda dan Secret Token yang sesuai dengan SECRET_TOKEN di Code.gs.

2

Simpan & Hubungkan

Klik tombol Simpan. Jika indikator berubah menjadi Hijau, aplikasi sudah terhubung ke database cloud.

3

Scan & Transaksi

Buka tab SCAN untuk mulai bekerja. Pilih mode Masuk atau Keluar, lalu scan stiker barang.

4

Auto-Sync Realtime

Data akan otomatis terkirim. Jika offline, data tersimpan aman di HP dan akan sinkron otomatis saat internet kembali tersedia.
